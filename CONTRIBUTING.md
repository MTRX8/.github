# Contributing to MTRX8

Thank you for your interest in MTRX8.

MTRX8 is an open-source initiative exploring how the ideas behind **Metro** can continue to inspire modern applications.

## Contribution status

**MTRX8 is currently not accepting external contributions.**

At this stage, the projects are being developed and shaped internally. For that reason, we are not currently accepting:

* Pull requests
* Code contributions
* Feature implementations
* Design contributions
* Documentation contributions
* External project submissions

This is a temporary project policy and may change as the MTRX8 ecosystem evolves.

## Why is the source public?

Although external contributions are currently closed, MTRX8 projects are intentionally developed in the open.

The source code is available so that people can:

* Explore how the projects work
* Learn from the implementation
* Experiment with the ideas
* Fork and modify the projects
* Build independent projects based on them
* Follow the evolution of the ecosystem

Being open source does not necessarily mean that every repository is accepting contributions at every stage of its development.

## Reporting issues

While contributions are currently closed, **bug reports and issue discussions may be available on individual repositories**.

Before opening an issue, please check the repository's issue guidelines and existing issues.

When reporting a bug, provide enough information to reproduce it whenever possible, including:

* What happened
* What you expected to happen
* Steps to reproduce the problem
* Relevant logs or error messages
* Operating system and version
* Application or package version
* Relevant environment information

Please do not include sensitive or private information in an issue.

## Feature requests

Feature requests are not currently being accepted as contributions.

Existing repositories may still contain discussions or issue trackers where future ideas are documented internally. Their availability does not imply that submitted feature requests will be implemented.

## Forking and experimentation

You are free to fork MTRX8 projects according to the terms of their respective licenses.

We encourage experimentation.

You can modify the projects, explore alternative implementations, create your own applications, and develop new ideas inspired by the work.

If you create something based on MTRX8, we would be interested in seeing what you build, even though we are not currently accepting contributions back into the official repositories.

## Future contributions

When MTRX8 is ready to accept external contributions, this document will be updated with information about:

* Development setup
* Contribution workflow
* Branching strategy
* Commit conventions
* Pull request requirements
* Testing requirements
* Code style
* Design guidelines
* Review process
* Code of Conduct

Until then, please consider the repositories **read-only from a contribution perspective**, while remaining free to study, fork, and experiment with the source under its applicable license.

## Code of Conduct

As MTRX8 is not currently accepting external contributions, the project does not currently maintain an active contributor community or contributor-specific Code of Conduct.

This may be introduced when external contributions are opened.
