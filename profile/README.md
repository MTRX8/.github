# Metro Experience

MTRX8 is an open-source initiative dedicated to building modern applications inspired by the Metro design language introduced by Microsoft with Windows Phone.

We believe Metro was more than a visual style. It was a different way of thinking about interfaces — putting content, typography, motion, and personality at the center of the experience.

MTRX8 explores how those principles can live on across today's platforms.

## Projects

This organization hosts applications, libraries, components, design resources, experiments, and other tools that help bring the language to modern platforms.

## Contributing

MTRX8 is currently not accepting external contributions.

The repositories are public so that the work can be explored, studied, forked, and built upon under the terms of their respective licenses. However, pull requests, feature submissions, and other direct contributions are not being accepted at this time.
